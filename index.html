Configurar Google Gemini API Key

¿Cómo obtener tu API Key gratuita de Gemini?

  1. Entra a Google AI Studio e inicia sesión con cualquier cuenta de Google.
  2. Haz clic en el botón superior que dice "Get API key" (Obtener clave de API).
  3. Crea o selecciona un proyecto y copia tu clave (comienza con AQ... o AIza...).
  4. Pégala en el campo de abajo. Se guardará de forma privada solo en tu navegador (localStorage).
